# Evony: Concept Art & World Building
**A Professional Game Design & UI/UX Proposal**

## Overview
This project documents my journey from a long-term player (6+ years) to a professional **Creative Game Designer**. It presents a complete visual and strategic overhaul concept for in-game events, specifically focusing on the **"Ancestral Banner Rescue"**.

##  Key Features
* **Original Concepts:** 100% original gameplay mechanics and UI/UX layouts.
* **Visual Assets:** High-fidelity character art and environmental assets developed with AI-assisted creative workflows.
* **Official Recognition:** Concept officially submitted and acknowledged by the development team.

##  Tech Stack
* **Frontend:** HTML5, CSS3 (Bento Grid Layout).
* **Design Tools:** Photoshop, AI-Enhanced Visualization Tools.
